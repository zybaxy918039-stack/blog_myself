部署设置

推送会自动完成构建与上线：文章放进 content/posts/，图片放进 content/uploads/，代码改动直接推到 main 分支即可。

首次部署前需要配置一次

  1. 在 Cloudflare 创建 API Token：Account 下 D1、R2、Workers Scripts、Pages 的编辑权限。
  2. 在 GitHub 仓库的 Secrets and variables > Actions 中添加 CLOUDFLARE_API_TOKEN。
  3. 再添加 CLOUDFLARE_ACCOUNT_ID。
  4. 推送到 main 触发 Actions：自动创建 D1（默认 blog-comments-db）与 R2（默认 blog-attachments），执行初始表结构，再部署 Pages。
  5. 部署成功后，在 Cloudflare Pages 项目设置里绑定你的自定义域名，之后所有更新都由每次推送自动完成。
详细步骤与本地手动部署命令见部署辅助页：deploy.html
