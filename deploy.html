部署到 Cloudflare Pages

部署由 GitHub Actions 完成，本页面只负责生成清单与本地命令，不会在浏览器里保存你的令牌。

自动化流程

把文章、图片或代码推送到 GitHub 的 main 分支后，Actions 会自动创建 D1 数据库与 R2 存储桶、执行初始表结构，然后构建并部署这个博客。
你只需要在第一次部署前完成 Cloudflare API Token 和两个 GitHub Secrets 的配置。

关键说明

  1. API Token 只需要创建一次。 在 Cloudflare 仪表盘创建 Token，权限至少包含：Account 下的 D1 编辑、R2 编辑、Workers Scripts 编辑、Pages 编辑。
  2. 两个 Secrets 也只配置一次。 在 GitHub 仓库 Settings → Secrets and variables → Actions 中添加 CLOUDFLARE_API_TOKEN 和 CLOUDFLARE_ACCOUNT_ID。
  3. D1 与 R2 会自动创建。 数据库名默认 blog-comments-db，存储桶默认 blog-attachments，可通过同名环境变量覆盖。
  4. 自定义域名只需绑定一次。 在 Cloudflare Pages 的项目设置里把你在 Cloudflare 托管的域名加为自定义域名即可。
  5. 之后每次推送自动更新。 文章放入 content/posts/，图片放入 content/uploads/，推送到 main 就能看到线上更新。

部署页面属于首次部署辅助工具，正式站点导航中不会显示入口。
