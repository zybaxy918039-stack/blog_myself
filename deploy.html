部署指南

  1. 确保你的博客代码已提交到 GitHub 仓库
  2. 填写正确的 GitHub 仓库地址
  3. 点击「开始部署」按钮
  4. 在 Cloudflare Dashboard 中完成授权
  5. 等待部署完成
  6. 绑定自定义域名（可选）
